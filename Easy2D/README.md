# ⚡ Easy 2D Tools for Godot 4

> Удобная и быстрая док-панель для ускорения разработки 2D-игр и интерфейсов в Godot 4. Спавн базовых нод в один клик, сборные игровые префабы, гибкие настройки поведения и мощные утилиты редактирования прямо в редакторе.

---

## 🚀 Основные возможности

Плагин разделен на 4 функциональных раздела с быстрым доступом через док-панель справа:

### 1. 📦 Ordinary (Базовые узлы)
Мгновенное создание часто используемых 2D и UI компонентов:
* **UI**: `Button`, `Label`, `Control`, `HBoxContainer`, `VBoxContainer`, `TextureRect`, `ColorRect`, `ProgressBar`, `LineEdit`.
* **2D & Физика**: `Sprite2D`, `Camera2D`, `CharacterBody2D`, `Area2D`, `CollisionShape2D`.
* **Умный спавн**: автоматическое назначение `owner` для сохранения в файл сцены, прикрепление к выбранному узлу или в корень, полная поддержка истории отмены действия (**Ctrl + Z**).

### 2. 🧩 Extended (Расширенные ноды и сборные префабы)
* **Продвинутые 2D-ноды**: `TileMapLayer`, `AnimatedSprite2D`, `GPUParticles2D`, `PointLight2D`, `RayCast2D`, `Parallax2D`.
* **Готовые префабы в 1 клик**:
  * `+Player Base` — готовый персонаж (`CharacterBody2D` + `Sprite2D` + `CollisionShape2D` с настроенной капсулой + `Camera2D`).
  * `+Coin / Item` — готовый триггер предмета (`Area2D` + `Sprite2D` + круглая коллизия).
  * `+HealthBar UI` — готовый прогресс-бар здоровья со слоем текста `100 / 100`.

### 3. ⚙️ Settings (Глубокая кастомизация)
* **Внешний вид**: переключение цветовых тем дока (`Dark Mode`, `Light Mode`, кастомный цвет фона).
* **Поведение спавна**:
  * `Spawn Center` — размещение объекта строго в центре текущего 2D-вьюпорта камеры редактора.
  * `To Parent / To Root` — спавн внутрь выделенного узла или принудительно в корень сцены.
  * `Auto Select` — автоматическое выделение созданного объекта в инспекторе.
* **Автоматизация 2D**:
  * `Pixel Art` — автоматическое переключение фильтрации текстуры в `Nearest` без размытия.
  * `Auto Shape` — автоматическое создание `RectangleShape2D` (32x32) внутри `CollisionShape2D` без предупреждений движка.
  * `Prefix UI / Node` — автодобавление системных префиксов к именам (`UI_`, `Obj_`).
* **Сохранение**: автоматическая запись пользовательской конфигурации в `config.cfg`.

### 4. 🛠️ Edit (Быстрые манипуляции со сценой)
* **Transform & Align**: привязка к сетке 16x16 (`Snap to Grid`), сброс позиции (`Reset Pos`), центрирование и сброс пивота (`Center Pivot` / `Reset Pivot`), быстрое отзеркаливание (`Flip H` / `Flip V`).
* **Hierarchy**: оборачивание выделенных нод в группу (`Group Nodes`), роспуск группы (`Ungroup`), изменение порядка слоев (`Move to Top` / `Move to Bottom`), быстрое дублирование со смещением (`Duplicate +`), безопасное удаление через `UndoRedo` (`Delete Safe`).
* **Visuals & Physics**: автоматическая подгонка размера формы коллизии под спрайт (`Fit Collision`), очистка текстур и шейпов, дублирование ресурсов (`Make Unique`), быстрое добавление тени (`Add Shadow`) и света (`Add Light`).
* **Scripts**: быстрое создание базового скрипта (`Attach Script`) и мгновенный переход к редактированию (`Open Script`).
